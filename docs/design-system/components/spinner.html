Spinner

Compact circular indicator for short indeterminate operations like Bluetooth scanning or Coach thinking.

WCAG 2.2 AAStatus: stablerole="status"

Overview

Use a spinner for brief inline work (scanning for Polar H10, submitting a Coach message). For full-page initial loads, prefer Skeleton placeholders.

Anatomy

  1. Ring20px (or 40px .spinner--lg) border ring rotating via CSS keyframes.
  2. Status textVisible or visually hidden description.
