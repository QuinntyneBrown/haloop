Form field

The vertical wrapper pairing label, optional hint, input control, character counter and validation error.

Overview

Every input, select and textarea in Haloop lives inside .field so spacing between label, control, help text and error message is identical across Settings, Onboarding and Dialogs.

Anatomy

  1. Label (.field__label)Medium 14px text, optional muted tag.
  2. ControlText field, select or textarea.
  3. Help / Error14px text linked via aria-describedby; error includes ⚠ prefix.

Responsive behaviour

  • Stacks vertically at every breakpoint; labels always sit above controls so narrow screens never clip.

Theming

Error messages use --color-danger-fg, verified ≥ 4.5:1 on both canvas and card surfaces.
