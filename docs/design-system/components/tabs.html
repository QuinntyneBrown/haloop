Tabs

Horizontal underline tabs switching related views within the same page without losing context.

WCAG 2.2 AAStatus: stableAPG Tabs

Overview

Use tabs to switch peer views of the same dataset (for example, All sessions / Strength / Runs). Never wrap tabs onto two rows; allow horizontal scroll instead.

Anatomy

  1. Tab listHorizontal strip with bottom hairline border.
  2. Tab button44px tall trigger with optional count badge.
  3. Active underline2px --color-accent bar flush with the bottom rule.

Variants

Sizes

Tabs use a single 44px height.

States

DefaultHoverSelectedFocus

Both themes

Responsive behaviour

  • Scrolls horizontally via overflow-x: auto on narrow viewports; never wraps to two lines.

Theming

Selected label uses --color-fg-accent and indicator uses --color-accent.

Accessibility

Role and pattern

WAI-ARIA APG Tabs: role="tablist", role="tab", aria-selected and role="tabpanel".

Keyboard

KeyAction
Left / RightMoves focus between tabs.
Home / EndJumps to first or last tab.

Focus

Roving tabindex keeps only the active tab in the Tab order.

Labelling

Tablist has an aria-label; each tabpanel references its tab with aria-labelledby.

Contrast

Selected tab text on surface
Inactive tab text on surface

Motion

Underline fades in over --duration-fast.

Touch

44px minimum height for comfortable thumb taps.

Content

  • Keep tab labels to 1–2 words.

Do and don't

Tokens

PartTokenLightDark
Selected text--color-fg-accent
Indicator--color-accent
Min height--target-comfortable

Code

<div class="tabs" role="tablist" aria-label="Session views">
  <button class="tab" role="tab" aria-selected="true">Summary</button>
  <button class="tab" role="tab" aria-selected="false">Splits</button>
</div>
Class / attributeEffect
.tabsHorizontal tablist container.
.tabIndividual tab button; active when aria-selected="true".
