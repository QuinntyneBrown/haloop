Layout primitives

Container, grid, stack and cluster utilities that compose every Haloop screen with token-driven rhythm.

Overview

Instead of one-off margin classes, compose every screen from four primitives: .container (horizontal cap + margins), .stack (vertical spacing), .cluster (wrapping horizontal row) and .grid (responsive columns).

Anatomy

  1. .containerMax width --layout-container-max with --layout-margin inline padding.
  2. .stackFlex column with --space-4 (--space-2 sm, --space-8 lg) gap.
  3. .clusterWrapping flex row with --space-3 gap.
  4. .gridCSS Grid driven by --layout-columns and --layout-gutter.

Responsive behaviour

  • .grid automatically switches from 4 → 8 → 12 columns via tokens.
  • .cluster wraps naturally when items exceed 360px.
