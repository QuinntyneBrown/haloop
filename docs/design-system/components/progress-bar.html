Progress bar

Determinate download bars, indeterminate work indicators and AI Lab's 2 GB cache budget bar.

WCAG 2.2 AAStatus: stablerole="progressbar"

Overview

Use progress bars when a task takes more than two seconds and progress can be measured (such as downloading Qwen2.5-0.5B-Instruct: 212 / 480 MB) or to visualize local storage usage in AI Lab.

Anatomy

  1. Meta label & valueLeft-aligned label and right-aligned tabular readout.
  2. Track8px pill track (--color-bg-surface-sunken).
  3. FillWidth controlled via --value custom property.

Variants

Sizes

Progress and budget tracks are both 8px (--space-2).

States

Determinate (44%)Halo budget fill

Both themes

Responsive behaviour

  • Fills 100% of its parent container width.

Theming

Uses --color-accent (or --color-halo / --color-success-solid) on --color-bg-subtle-hover.

Accessibility

Role and pattern

role="progressbar" with aria-label, aria-valuenow, aria-valuemin and aria-valuemax.

Keyboard

KeyAction
NoneNon-interactive readout.

Focus

Not focusable.

Labelling

Always pair with a visible label and percentage or MB readout.

Contrast

Accent bar on surface

Motion

Width transitions over --duration-slow; indeterminate animation stops under reduced motion.

Touch

Non-interactive.

Content

  • Show concrete units ("212 / 480 MB · 44%") rather than a bare bar.

Do and don't

Tokens

PartTokenLightDark
Fill--color-accent
Track--color-bg-subtle-hover
Height--space-2

Code

<div class="progress" role="progressbar" aria-label="Download" aria-valuenow="44" aria-valuemin="0" aria-valuemax="100">
  <div class="progress__bar" style="--value: 44%;"></div>
</div>
Class / attributeEffect
.progress / .progress__barStandard progress bar driven by --value.
.budget-box / .budget-barAI Lab storage budget variant.
