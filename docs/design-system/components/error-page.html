Error page

Overview

Full-page error states use .auth-layout and .container--narrow to centre a clear diagnosis, what still works locally, and a single primary recovery button.

Anatomy

  1. Brand markReassures the user they are still in Haloop.
  2. Status cardIcon, h1 diagnosis, capability summary and recovery CTA.

Variants

Three Haloop fallback routes: /404 (Not found), /offline (Offline mode) and /unsupported (Browser lacks WebGPU/Web Bluetooth).

Sizes

Error pages cap content at .container--narrow (42rem).
