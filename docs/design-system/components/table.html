Table

Structured data tables with sticky headers, sorting, tabular numbers and horizontal scroll wrappers.

Overview

Use tables for multi-column comparisons like workout history logs and exercise split breakdowns. Wrap every table in .table-wrap so narrow viewports scroll horizontally inside the card rather than overflowing the page.

Anatomy

  1. Scroll wrapper (.table-wrap)Rounded border frame with overflow-x: auto.
  2. Sticky headerSunken surface row with muted labels and optional aria-sort.
  3. Numeric cells (.num)Right-aligned tabular figures.

Responsive behaviour

  • .table-wrap provides clean horizontal scrolling at 360px.
  • @media (hover: none) keeps .row-actions visible on touch devices.

Theming

Headers use --color-bg-surface-sunken; hovered rows use --color-bg-subtle; selected rows use --color-accent-subtle.

Accessibility

Role and pattern

Native <table> with <caption>, scope="col" and aria-sort on sortable headers.

Keyboard

KeyAction
TabMoves through sort buttons, row links and row actions.

Focus

Row actions reveal on :focus-within as well as hover.

Labelling

Provide a visible or visually hidden <caption>.

Row actions stay visible on touch screens.

Content

  • Right-align numeric columns with .num; keep column headers concise.
