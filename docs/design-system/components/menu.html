Menu

Dropdown action menus group secondary actions, keyboard shortcuts and destructive items behind a single trigger.

WCAG 2.2 AAStatus: stableAPG Menu Button

Overview

Use a menu when a toolbar or table row needs three or more actions without cluttering the row. Keep primary actions outside the menu.

Anatomy

  1. Menu panelRaised surface with --shadow-3, --radius-md and 4px padding.
  2. Menu item36px height row with optional leading icon and trailing shortcut.
  3. DividerHairline separator grouping destructive items at the bottom.

Variants

Default, hovered, disabled and danger menu items with divider.

Sizes

Menus use a single 36px item density.

States

DefaultHoverDisabledDanger

Both themes

Responsive behaviour

  • Flips alignment to stay inside viewport margins; never overflows horizontally at 360px.

Theming

Uses --color-bg-surface-raised, --color-bg-subtle on hover, and --color-danger-fg for destructive items.

Accessibility

Role and pattern

WAI-ARIA APG Menu Button: trigger sets aria-haspopup="menu" and aria-expanded; list uses role="menu" and role="menuitem".

Keyboard

KeyAction
Down / UpMoves focus between menu items.
Enter / SpaceActivates the focused item and closes the menu.
EscCloses the menu and returns focus to the trigger.

Focus

Focus moves to the first item when opened and returns to the trigger on close.

Labelling

Menu is labelled by its trigger button via aria-labelledby.

Contrast

Menu text on raised surface
Danger item on raised surface

Motion

Scales in over --duration-fast; zeroed under reduced motion.

Touch

36px item height exceeds 24px minimum with generous horizontal tap width.

Content

  • Start each item with a verb; place destructive actions last beneath a divider.
