Switch

Binary on/off toggle for live settings like voice cues, camera overlay and auto-pause.

WCAG 2.2 AAStatus: stablerole="switch"

Overview

Use a switch for an immediate on/off preference. Unlike checkboxes in a multi-select list, switches represent a setting that is either active or inactive.

Anatomy

  1. Track44×24px pill track transitioning from --color-border-strong to --color-accent.
  2. Thumb20px circular knob with --shadow-1.
  3. LabelNames the setting, not the action.

Variants

Sizes

Switches have a single 44×24px track size.

States

OffOnFocusDisabled

Both themes

Responsive behaviour

  • 44px track width already meets comfortable touch size on phones.

Theming

Track shifts from --color-border-strong to --color-accent; thumb uses --color-bg-surface.

Accessibility

Role and pattern

<input type="checkbox" role="switch">.

Keyboard

KeyAction
SpaceToggles the switch on or off.

Focus

2px focus ring around the pill track.

Labelling

Label describes the setting ("Spoken Coach cues") rather than a verb.

Contrast

Off track on surface
On track on surface

Motion

Thumb slides over --duration-base; instant under reduced motion.

Touch

44×24px track plus full label width.

Content

  • Keep the label constant regardless of on/off state.
