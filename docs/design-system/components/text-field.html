Text field

Overview

Use text fields for short free-form entries like athlete display name, Scripture search queries, Bluetooth device PINs and cache budget limits. Always pair with a form field label.

Anatomy

  1. LabelAlways visible above the control; linked with for/id.
  2. Input box40px tall, --color-border-strong (≥ 3:1 contrast), --radius-md.
  3. Help or error textLinked via aria-describedby.

Variants

MB
Standard text, search with leading icon, and numeric input with suffix addon.

Sizes

States

DefaultHoverFocusInvalidDisabledRead-only

Both themes

Responsive behaviour

  • Always width: 100% inside its column; never overflows 360px viewports.

Theming

Uses --color-bg-surface, --color-border-strong and --color-danger-solid when invalid.

Accessibility

Role and pattern

Native <input> with appropriate type and autocomplete (WCAG 1.3.5).

Keyboard

KeyAction
TabMoves focus into and out of the input.
EnterSubmits the enclosing form.

Focus

2px --color-focus-ring outline with 0 offset and matching border colour.

Labelling

Always pair with <label for>; never rely on placeholder text as a label.

Contrast

Input text on surface
Placeholder on surface
Border on surface
Invalid border on surface

Motion

Border and shadow transition over --duration-fast.

Touch

Default height 40px meets touch comfort; font size ≥ 16px prevents iOS Safari auto-zoom.

Content

  • Use sentence-case labels; mark optional fields with (optional) instead of asterisks.
