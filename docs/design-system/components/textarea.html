Textarea

Multi-line text entry for workout reflections, Coach questions and session notes.

Overview

Use a textarea when the person may write more than one line, such as asking Haloop Coach a question or recording post-workout notes in the Finish workout dialog.

Anatomy

  1. LabelVisible above the textarea.
  2. Resizable boxMinimum 2.5× control height with vertical resize.
  3. Counter (optional)Right-aligned caption showing character count.

Variants

Sizes

Textareas use medium text size and grow vertically via rows.

States

DefaultFocusInvalidDisabled

Both themes

Responsive behaviour

  • Full width of its container; vertical resize only so horizontal layout never breaks.

Theming

Shares surface, border and focus tokens with .input.

Accessibility
