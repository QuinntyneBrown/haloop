Radio group

Mutually exclusive choices for Bluetooth device pairing, workout intensity and backend selection.

Overview

Use a radio group when the person must pick exactly one option from 2–5 visible choices, such as selecting a Bluetooth sensor in the Pair device dialog.

Anatomy

  1. LegendNames the group for visual and screen-reader users.
  2. Radio circle20px circular input with centered dot when selected.
  3. Option labelTitle plus optional hardware metadata.

Variants

Workout focus

Sizes

Radio inputs use one standard 20px circle.

States

UnselectedSelectedFocusDisabled

Both themes

Responsive behaviour

  • Stacks vertically by default on all viewports for easiest scanning.

Theming

Selected fill uses --color-accent with --color-fg-on-accent center dot.

Accessibility

Role and pattern

Native <input type="radio"> sharing one name inside <fieldset>.

Keyboard

KeyAction
Up / Down / Left / RightMoves selection within the group.
TabMoves focus into/out of the group.

Focus

2px focus ring around the active radio circle.

Labelling

<legend> provides the group name.

Contrast

Selected dot on accent
Border on surface

Motion

Transitions over --duration-fast.

Touch

Full row is tappable and ≥ 24px tall.

Content

  • Always pre-select the safest or recommended option when one exists.

  <legend>Device to pair</legend>
  <label class="choice"><input type="radio" name="dev" checked><span>Polar H10</span></label>
