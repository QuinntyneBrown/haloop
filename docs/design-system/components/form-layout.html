Overview

Forms in Haloop default to a single column capped at --layout-measure (65ch) with .stack spacing, a top .form-summary alert on failed submit, and a .form-actions footer.

Anatomy

  1. Error summary (.form-summary)Appears above fields on invalid submit and receives focus.
  2. Fields (.stack)16px vertical gap between fields.
  3. Actions bar (.form-actions)Cancel/Reset followed by primary submit.

Variants

Responsive behaviour

  • Single column on phones; actions stack or wrap cleanly.

Accessibility

Role and pattern

Native <form novalidate> with focus moved to .form-summary on validation error.

Keyboard

KeyAction
EnterSubmits the form from single-line inputs.

Focus

Moves to error summary (tabindex="-1") when submission fails.

Labelling

Each link in the error summary jumps directly to the invalid field's id.

Contrast

Summary text on danger bg

Motion

Submit button transitions to spinner when aria-busy="true".

Touch

Primary submit action ≥ 40px tall.

Content

  • Error summary heading states the exact count: "Fix 2 problems before saving".
