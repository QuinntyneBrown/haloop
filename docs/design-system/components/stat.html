Stat / KPI

Tabular numeric metric readouts with directional deltas for Today's streak, weekly volume and session scores.

Overview

Use .stat inside a .card and .kpi-grid to highlight key workout metrics: 11-day streak, 94% form score, 138 avg bpm or 286 MB cached.

Anatomy

  1. LabelMuted 14px metric name.
  2. ValueOutfit h2 with tabular-nums so live updates never jitter.
  3. Delta (optional)Directional arrow + sign + colour.

Responsive behaviour

  • .kpi-grid auto-fits columns down to 12rem, stacking cleanly on 360px phones.

Theming

Positive deltas use --color-success-fg; negative deltas use --color-danger-fg.

Accessibility

Role and pattern

Plain text; deltas combine arrow (↑/↓), sign (+/-) and colour so direction is perceivable without colour (WCAG 1.4.1).
