Toast

Transient inverse-surface notifications confirming model downloads, cache removals and Bluetooth events.

WCAG 2.2 AAStatus: stablerole="status" / role="alert"

Overview

Toasts report background completion or sensor events without interrupting the current screen. Info and success toasts auto-dismiss after ≥ 8 seconds (pausing on hover/focus); danger toasts persist until dismissed.

Anatomy

  1. Status iconTinted semantic icon (info, success, warning, danger).
  2. Title & bodyInverse text with optional Undo/Retry action.
  3. Dismiss button & timer bar24px close target and subtle bottom progress rule.

Variants

Responsive behaviour

  • Full width along the bottom edge below 640px; 24rem docked bottom-right at 640px+.

Theming

Uses --toast-bg (--color-bg-inverse) and --toast-fg (--color-fg-inverse).

Accessibility

Role and pattern

Polite toasts sit inside role="status" aria-live="polite"; errors use role="alert".

Keyboard

KeyAction
TabReaches the toast action and dismiss button; pauses auto-dismiss.

Focus

Never steals focus when appearing.

Labelling

Dismiss button sets aria-label="Dismiss notification".

Contrast

Toast text on inverse bg

Motion

Exit fades over --duration-base; zeroed under reduced motion.

Touch

Dismiss button meets 24px minimum target.

Content

  • Keep titles to 2–4 words and body to one sentence.
