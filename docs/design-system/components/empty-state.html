Empty state

Centered icon, title, one-sentence explanation and primary recovery action for zero-data and filtered screens.

Overview

Every collection in Haloop (Today, Train, Coach, History, Devices, AI Lab) defines a calm empty state explaining why nothing is shown and offering one clear primary action.

Anatomy

  1. Icon badge64px circular icon tinted with --color-accent-subtle (or --color-danger-bg for errors).
  2. Title & texth3 title + max 36ch muted sentence.
  3. ActionsOne primary button + optional secondary link.
