Overview

Use .dl whenever displaying labelled attributes of a single entity (a completed workout, a Bluetooth strap or browser WebGPU diagnostics).

Anatomy

  1. Term (<dt>)Muted label column sized to max-content.
  2. Value (<dd>)Default ink value, tabular when numeric.
