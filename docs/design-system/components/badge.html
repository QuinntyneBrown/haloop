Badge & status

Tinted status pills, numeric counts and live 8px status dots for AI readiness and Bluetooth sensors.

Overview

Badges communicate status at a glance: Available, Ready, Flag off, Connected or WASM fallback. Every tinted badge pairs a leading colour dot with uppercase overline text so meaning never depends on colour alone.

Anatomy

  1. Status dotLeading dot inheriting currentColor (or standalone 8px .status-dot).
  2. LabelShort uppercase overline text inside a 24px pill.

Motion

Touch

Non-interactive; for interactive toggles use Chip.

Content

  • Keep badge labels to 1–2 words.
