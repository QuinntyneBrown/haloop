Tooltip

Compact inverse-surface hint revealing the label or shortcut for icon-only controls.

WCAG 2.2 AAStatus: stablerole="tooltip"

Overview

Use tooltips to label icon-only buttons on hover and focus. Never put interactive links or critical instructions inside a tooltip.

Anatomy

  1. Trigger (.has-tooltip)Relative anchor wrapping the control.
  2. Bubble (.tooltip)Inverse surface, caption type, CSS arrow pointer.

Variants

Settings (T)

Sizes

Tooltips have one compact size.

States

Visible (hover/focus)
Shortcut: T

Both themes

Remove model
Remove model

Responsive behaviour

  • Never relied on for essential information on touch-only screens.

Theming

Uses --color-bg-inverse and --color-fg-inverse so contrast stays ≥ 16:1 in both themes.

Accessibility

Role and pattern

role="tooltip" linked from its trigger via aria-describedby.

Keyboard

KeyAction
TabShows tooltip on focus.
EscDismisses tooltip without moving focus.

Focus

Tooltip itself never receives focus.

Labelling

Never replaces aria-label on an icon button.

Contrast

Tooltip text on inverse bg

Motion

Opacity fades over --duration-fast.

Touch

Touch users rely on visible labels or confirmation text.

Content

  • Keep tooltips under 4 words.
