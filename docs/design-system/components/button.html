Button

Buttons trigger actions: start a workout, download a model, pair a device or confirm a removal.

WCAG 2.2 AAStatus: stableNative <button>

Overview

Use a button when activating it performs an action or changes state. Use a link for navigation and a menu when one trigger reveals several secondary actions. Haloop adds .btn--pill for rounded Download CTAs in AI Lab.

Anatomy

  1. Leading icon (optional)1.25em square, inherits label colour, aria-hidden.
  2. LabelVerb phrase in sentence case; serves as the accessible name.
  3. ContainerHeight from --control-height-*, --radius-md (or --radius-full with .btn--pill).

Variants

Primary, secondary, ghost, link, danger, Haloop pill download and icon-only.

Sizes

Heights from --control-height-sm/md/lg.

Responsive behaviour

  • Below 768px, primary header and form buttons expand to full width via .btn--block.
  • Dialog footers wrap cleanly when button labels exceed viewport width, keeping primary last.

Theming

Uses component tokens --btn-bg, --btn-fg, --btn-border, --btn-bg-hover and --btn-bg-active mapped to semantic tokens. In dark theme, primary flips to Halo gold with deep ink text.

Accessibility

Role and pattern

Native <button type="button"> or type="submit". Follows the WAI-ARIA Button pattern without needing an explicit role.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the button.
Enter, SpaceActivates the button.

Focus

2px --color-focus-ring with 2px offset on :focus-visible.

Labelling

Visible text is the accessible name. Icon-only buttons require aria-label and a tooltip; loading sets aria-busy="true".

Contrast

Primary label on accent
Danger label on danger solid
Secondary border on surface
Focus ring on surface

Motion

Background and border transition over --duration-fast; zeroed under reduced motion. Loading spinner continues rotating.

Touch

Small (36px), medium (40px) and large (48px) all exceed the 24px WCAG 2.5.8 minimum.

Content

  • Use concise verb phrases in sentence case: "Start workout", "Pair device", "Remove model".
  • Destructive buttons name what will be removed.
