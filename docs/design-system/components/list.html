Overview

Lists display repeating rows without full table chrome. Haloop uses three list structures: generic .list, 2-column .builtin-grid (Chrome Gemini Nano APIs) and 4-column responsive .model-list (Hugging Face open models).

Anatomy

  1. Primary columnTitle + monospace repo link or metadata.
  2. Secondary columnsTask description and tabular file size (visible ≥ 768px).
  3. Trailing actionReady status + delete button, or Download pill.

Responsive behaviour

  • .builtin-grid shifts from 1 to 2 columns at 640px.
  • .model-row shifts from 2 columns (title + action) to 4 columns at 768px.

Theming

Hairline dividers use --color-border-default; hover uses --color-bg-subtle.

Accessibility

Role and pattern

Semantic <ul> / <li>; interactive rows use real links or buttons.

Keyboard

KeyAction
TabMoves through interactive links and action buttons inside each row.

Focus

Individual links and buttons show the shared 2px focus ring.

Labelling

Row trash buttons include the model name in aria-label ("Remove Rep counting model").
