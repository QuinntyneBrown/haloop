Chip

Interactive filter toggles and removable tag pills for workout history and Scripture topics.

Overview

Use chips for quick multi-filter toggles (Strength, Cardio, Mobility) or removable search criteria. Unlike static badges, chips are interactive buttons.

Anatomy

  1. Pill container36px tall, --radius-full, --color-border-strong.
  2. Label14px medium text.
  3. Remove button (optional)Labelled close icon inside removable chips.

Variants

KJV

Sizes

Chips use --control-height-sm (36px).

States

DefaultHoverSelectedFocus

Both themes

Responsive behaviour

  • Wrap inside a .cluster so filter rows reflow cleanly on phones.

Theming

Uses --chip-bg, --chip-fg and --chip-border; selected flips to --color-accent-subtle.

Accessibility

Role and pattern

Filter chips are <button type="button" aria-pressed="true|false">.

Keyboard

KeyAction
Enter / SpaceToggles filter state.

Focus

Shared 2px focus ring.

Labelling

Removable chip close buttons include the chip name in aria-label.

Contrast

Selected text on accent subtle
Border on surface

Motion

Background transitions over --duration-fast.

Touch

36px height exceeds 24px minimum.

Content

  • Keep filter labels to 1–2 words.
