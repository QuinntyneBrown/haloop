Checkbox

Single and grouped checkboxes for multi-select workout goals, model selections and agreements.

Overview

Use checkboxes when zero, one or many options can be selected independently. Group related checkboxes inside a <fieldset> with a <legend>.

Anatomy

  1. Box20×20px square with --radius-xs and checkmark on checked.
  2. Label & descriptionPrimary label plus optional muted description.

Variants

Models to pre-download

Sizes

Checkboxes use one 20×20px visual box inside a ≥ 24px target row.

States

UncheckedCheckedFocusInvalidDisabled

Both themes

Responsive behaviour

  • Labels wrap cleanly beside the 20px box without shifting alignment.

Theming

Checked fill uses --color-accent with --color-fg-on-accent checkmark.

Accessibility

Role and pattern

Native <input type="checkbox"> inside <label class="choice">.

Keyboard

KeyAction
SpaceToggles checked state.
TabMoves to next checkbox.

Focus

2px focus ring around the checkbox box.

Labelling

Wrapping <label> makes the entire row clickable; groups use <fieldset>/<legend>.

Contrast

Checkmark on accent
Unchecked border on surface

Motion

Background transitions over --duration-fast.

Touch

Row height meets --target-min and spans the full label width.

Content

  • Phrase labels positively so checking the box turns the feature on.
