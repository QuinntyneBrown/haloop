Link

Links navigate to another Haloop screen, session detail or external Hugging Face model repository.

Overview

Use a link whenever activation navigates to a URL or in-page anchor. Always underline inline links so they do not rely on colour alone (WCAG 1.4.1).

Anatomy

  1. Link textDescriptive destination text, underlined on hover and inline.
  2. External icon (optional)12px (.icon--xs) arrow indicating an external repository.

Variants

Responsive behaviour

  • Inline links wrap naturally with prose; repo links truncate with .truncate inside narrow model rows.

Theming

Uses --color-fg-link (deep Halo amber in light, luminous Halo gold in dark) and --color-fg-link-hover.

Accessibility

Role and pattern

Native <a href> element. External links opening a new tab include visually hidden "(opens in new tab)" text.

Keyboard

KeyAction
TabMoves focus to the link.
EnterFollows the link.

Focus

Shared 2px focus ring with 2px offset on :focus-visible.

Labelling

Link text must make sense out of context (WCAG 2.4.4).

Contrast

Link on surface
Link hover on surface

Motion

None; underline thickness shifts immediately on hover.

Touch

Standalone links in lists or footers sit inside rows ≥ 44px tall.

Content

  • Name the destination: "View session detail" or "Chrome AI setup guide", never "Click here".
