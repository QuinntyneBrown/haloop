Sidebar navigation

Always-ink 240px desktop navigation rail with Haloop brand mark, active Halo bar and live AI/device status footer.

Overview

Haloop's desktop rail (.app-sidebar) stays deep ink in both light and dark themes, anchoring the six primary routes (Today, Train, Coach, History, Devices, AI Lab) plus a live status footer showing WebGPU/Nano readiness and Polar H10 connection.

Anatomy

  1. Brand markOutfit 24px wordmark + gold halo monogram.
  2. Nav links44px rows; active route shows 2px left Halo gold indicator.
  3. Status footerLive AI engine and Bluetooth sensor status dots.

Responsive behaviour

  • Hidden below 64rem (1024px) where .phone-tabs and topbar take over.
  • Stretches full viewport height on desktop.

Theming

Uses dedicated --color-sidebar-* tokens so the rail remains dark ink in light mode and shifts slightly deeper (#0a0c10) in dark mode.

Accessibility

Role and pattern

<aside> containing <nav aria-label="Primary">; active link sets aria-current="page".

Keyboard

KeyAction
TabMoves through navigation links in order.
EnterNavigates to the selected route.

Focus

Halo gold focus ring has ≥ 8:1 contrast against the dark ink rail.

Labelling

Active state is announced via aria-current="page", not colour alone.

Contrast

Sidebar primary text
Sidebar muted text
Active halo indicator

Motion

Hover background transitions over --duration-fast.

Touch

44px link height meets comfortable touch targets.

Content

  • Use one- or two-word noun route names matching the topbar title.
