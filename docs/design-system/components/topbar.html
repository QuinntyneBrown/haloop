Overview

The Haloop top bar (.app-topbar) anchors every workspace screen at --layout-topbar-height (64px). On phones and tablets it displays the Haloop mark and circular Settings/AI Lab shortcut buttons, paired with the 4-item .phone-tabs bar at the bottom.

Anatomy

  1. Brand mark (mobile)Visible below 1024px when sidebar is hidden.
  2. Page titleTruncating h2 in Outfit display font.
  3. Action buttons36px circular utility buttons (.topbar-circle-btn).

Responsive behaviour

  • Below 1024px: brand mark, mobile-only circle actions and bottom .phone-tabs appear.
  • At 1024px+: sidebar takes over navigation and .phone-tabs hides.

Theming

Uses --color-bg-canvas with --color-border-default bottom hairline.

Accessibility

Role and pattern

<header> landmark; mobile bottom bar uses <nav aria-label="Primary"> with aria-current="page".

Keyboard

KeyAction
TabMoves through topbar links and action buttons.

Focus

2px focus ring; sticky header never obscures focused elements below it.

Labelling

Icon-only circle buttons carry explicit aria-label.

Contrast

Title on canvas
Muted phone tab on surface

Motion

Circle buttons transition over --duration-fast.

Touch

Phone tab items are ≥ 44px tall (--target-comfortable).

Content

  • Keep route titles to 1–2 words so they never truncate on 360px phones.
