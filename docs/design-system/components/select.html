Overview

Use native <select> for 4–15 mutually exclusive options. For 2–3 choices, prefer a radio group so all options stay visible.

Anatomy

  1. LabelVisible label above the control.
  2. Select boxNative select with custom chevron and 40px right clearance.

Variants

Sizes

Select controls use standard medium height (40px).

States

DefaultFocusInvalidDisabled

Both themes

Responsive behaviour

  • Native OS pickers open automatically on iOS and Android for ergonomic thumb selection.

Theming

color-scheme: light | dark ensures native option popups match the active theme.

Content

  • Keep option labels concise and avoid auto-submitting on change (WCAG 3.2.2).
