Stepper

Linear multi-step progress indicator used in Haloop's Welcome & setup onboarding flow.

Overview

Use a stepper for sequential flows with 2–4 clear steps (such as Profile → On-device AI → Ready). Completed steps show a green checkmark; the active step fills with accent ink or Halo gold.

Anatomy

  1. Step badge28px circle numbered automatically via CSS counters (or ✓ when complete).
  2. Step labelVisible on tablet/desktop; only current label stays visible on phones.

Variants

  1. Profile
  2. Models
  3. Wearables

Responsive behaviour

  • Below 48rem (768px), non-current step labels visually collapse to screen-reader-only text while preserving the current step label.

Theming

Current step uses --color-accent / --color-fg-on-accent; completed uses --color-success-fg.

Accessibility

Role and pattern

Semantic <ol class="stepper"> with aria-current="step" on the active step.

Keyboard

KeyAction
NoneRead-only progress indicator; navigation buttons live in the form footer.

Focus

Not focusable unless steps are interactive links.

Labelling

Hidden mobile labels stay in the accessibility tree so screen readers still announce all step names.

Content

  • Use 1–2 word nouns for step titles.
