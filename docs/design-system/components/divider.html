Overview

Haloop uses crisp 1px hairline rules (--color-border-default) extensively across AI Lab lists, sidebar footers and card footers to organize content without heavy boxes.

Anatomy

  1. Hairline rule1px solid --color-border-default with --space-6 vertical margin.

Variants

Section A
Section B

Sizes

Dividers are always 1px (--border-width-hairline).

States

Default

Both themes

Responsive behaviour

  • Spans 100% of its parent container width.

Theming

Uses --color-border-default (warm linen rule in light, ink-line in dark); raises to --color-border-strong under prefers-contrast: more.

Accessibility

Role and pattern

Native <hr> (or role="separator" inside menus). Purely decorative rules are exempt from 3:1 non-text contrast.

Content

  • Prefer whitespace first; add a divider only when adjacent groups need an explicit boundary.
