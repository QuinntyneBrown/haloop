Overview

Dialogs interrupt the current task for a focused decision or short form. Haloop uses five modal dialogs: Remove cached model (destructive), Pair Bluetooth device, Finish workout, Search Scripture and Enable Chrome built-in AI.

Anatomy

  1. BackdropFull-viewport --color-bg-backdrop scrim at --z-overlay.
  2. Header & iconOptional tinted status icon, h3 title and close button.
  3. Body & sticky footerScrollable body with sticky right-aligned actions.

Variants

Pair Bluetooth device

Select a nearby heart-rate monitor or watch.

Sizes

Three panel max-widths: .dialog__panel--sm (24rem), default (32rem), .dialog__panel--lg (48rem).

States

Busy submitFailed action

Responsive behaviour

  • Below 40rem (640px), dialogs dock to the bottom edge as a full-width sheet with --radius-xl top corners and a sticky footer.
  • At 640px+, dialogs centre with --radius-lg.

Theming

Uses --color-bg-surface-raised and --shadow-4.

Accessibility

Role and pattern

WAI-ARIA APG Dialog: role="dialog" aria-modal="true" aria-labelledby="..."; background page marked inert.

Keyboard

KeyAction
Tab / Shift+TabTrapped inside the dialog.
EscCloses the dialog (unless busy) and returns focus to the trigger.

Focus

Moves to the first interactive control (or cancel button on destructive confirmations) on open; restores to the trigger on close.

Labelling

aria-labelledby references .dialog__title.

Contrast

Body text on raised surface
Danger button label

Motion

Transitions respect prefers-reduced-motion.

Touch

Mobile bottom sheet places footer buttons within thumb reach.

Content

  • Title asks a clear question or names the task; destructive primary button repeats the verb ("Remove model").
