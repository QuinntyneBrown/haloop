Data tables & lists

Choosing between hairline lists and data tables, plus sorting, tabular numbers and mobile responsiveness.

Overview

Haloop uses clean hairline lists (.model-list, .builtin-grid, .list) for heterogeneous items with actions, and semantic .table for multi-column numeric comparisons.

When to use

  • Use Hairline lists for AI models, Chrome APIs and Bluetooth devices.
  • Use Tables for workout history and movement split logs.

Structure

States

Support loaded, loading (skeleton rows), empty, filtered no-results and error states.

Responsive behaviour

Tables scroll horizontally inside .table-wrap; .model-row collapses secondary columns below 768px.

Accessibility

Include table captions, scope="col", aria-sort and touch-visible row actions.

Content

Use tabular numerals (.num) and concise units.
