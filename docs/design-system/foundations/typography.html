Typography

Overview

Haloop uses three typeface families: Outfit for geometric, calm headings and live rep counters; Inter for UI copy, forms and dense lists; and JetBrains Mono for Hugging Face repository IDs, Chrome flags and code snippets.

Usage rules

  • Body stays 16px (--font-size-md); never set readable UI text below 12px (--font-size-xs).
  • Measure caps prose paragraphs at --layout-measure (65ch) for comfortable reading.
  • Tabular numbers (.tabular / font-variant-numeric: tabular-nums) are mandatory on heart rate, rep counters, cache budgets, timestamps and numeric table columns.
  • Headings apply --letter-spacing-tight and text-wrap: balance.

Accessibility

All sizes are authored in rem so browser zoom up to 200% and user root font preferences scale every control proportionally (WCAG 1.4.4). Line heights of 1.5 for body and 1.65 for Scripture quotes preserve readability under WCAG 1.4.12 text-spacing overrides.
