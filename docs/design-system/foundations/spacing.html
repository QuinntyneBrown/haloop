Foundation · Visual language

Spacing

A strict 4px spacing scale and three control heights that keep dense model lists and spacious devotional cards in visual rhythm.

4px base grid17 tokens
  • Overview
  • Scale
  • Usage
  • Tokens

Overview

Every padding, margin and gap sits on a 4px (0.25rem) grid. One-off pixel values discovered in the mocks (such as 6px budget bars and 7px status dots) were snapped to --space-2 (8px) during extraction.

Inside vs between rules

  • Inside components: use --space-1 through --space-6 (4px–24px). Cards and dialogs use --space-6 padding; compact lists use --space-3 × --space-4.
  • Between sections: use --space-6 through --space-12 (24px–48px) so groups separate clearly without extra borders.
  • Control heights: Haloop raises --control-height-sm to 2.25rem (36px) so pill download buttons and topbar icon buttons remain comfortable on touch screens while staying compact in rows.
