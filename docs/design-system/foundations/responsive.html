Overview

Haloop is designed mobile-first from 360px up to 1536px+, using min-width media queries in rem so layouts scale with browser font size.

Touch, pointer & testing rules

  • @media (hover: none) keeps table row actions permanently visible on touch devices.
  • All interactive targets meet --target-min (24px), and primary mobile actions meet --target-comfortable (44px).
  • Full-height shells use 100dvh so mobile browser toolbars do not clip bottom tabs.
  • Every page is verified at 360×800 and 1280×800 in both light and dark themes with zero horizontal overflow.
