Foundation · Visual language

Color

Warm linen paper, deep ink and Halo gold — structured in primitive and semantic tiers and verified to WCAG 2.2 AA in both themes.

Overview

Haloop pairs warm linen paper (#f5f2ea) and crisp card surfaces (#fbf9f4) with deep ink (#0f1217) for primary typography and the always-dark desktop navigation rail. Brand warmth comes from Halo gold (#e9a83a), balanced by live green for active sensors and on-device readiness, and terracotta for destructive actions and alerts.

Components never reference primitive palette tokens directly. Every colour passes through a semantic token so light, dark and high-contrast modes switch automatically.

Six colour ramps hold all raw hex values. Only tokens/tokens.css reads these variables.

Usage rules

  • Never use raw hex values in component CSS or templates. Always use a semantic token (--color-*).
  • Never communicate status by colour alone (WCAG 1.4.1). Pair every status colour with text and an icon or dot.
  • Reserve Halo gold (--color-halo) for the brand mark, active sidebar bar, verse card accent and dark-theme primary buttons; use --color-halo-deep or --color-fg-accent whenever gold appears as text on light paper.
  • Keep the desktop sidebar dark ink in both themes using --color-sidebar-* so navigation anchors the workspace.
