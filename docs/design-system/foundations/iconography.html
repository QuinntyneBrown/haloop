Overview

Haloop uses a single-weight 24×24 stroke icon set (stroke="currentColor", stroke-width="2", round caps and joins) plus the custom Haloop geometric H + gold halo mark.

Labelling rules

  • Icons paired with visible text are decorative: set aria-hidden="true" on the <svg>.
  • Icon-only buttons put the accessible name on the <button aria-label="...">, never on the SVG alone.
  • Replace inline style="width:0.75rem;height:0.75rem" with .icon--xs.
