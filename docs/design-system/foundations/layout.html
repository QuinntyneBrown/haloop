Layout

Overview

Haloop's layout is mobile-first. Three tokens — --layout-columns, --layout-gutter and --layout-margin — update automatically at 48rem (768px) and 64rem (1024px) so grids and containers adapt without per-component media queries.

Usage rules

  • Keep primary workspace content inside --layout-container-max (64rem / 1024px) so hairline lists stay scannable.
  • Use .grid--auto (minmax(min(100%, 18rem), 1fr)) for equal-weight cards and .kpi-grid for stat strips.
