Motion

Five durations and four easing curves that keep transitions crisp and automatically respect prefers-reduced-motion.

Reduced-motion ready9 tokens
  • Overview
  • Demos
  • Choreography
  • Reduced motion
  • Tokens

Overview

Motion in Haloop is calm and responsive — fast enough to feel immediate during a workout, never bouncy or distracting. All durations are zeroed automatically inside tokens.css under prefers-reduced-motion: reduce.

Interactive timing demos

--duration-fast + --ease-standard
--duration-base + --ease-enter
--duration-slow + --ease-exit
--duration-deliberate + --ease-spring

Choreography rules

  • Animate only compositor-friendly properties (opacity, transform / translate, color, background-color, border-color).
  • Continuous status indicators (.spinner) keep rotating under reduced motion because they communicate active work, whereas decorative shimmer (.skeleton) and indeterminate bars pause.

Reduced motion

@media (prefers-reduced-motion: reduce) sets --duration-fast/base/slow/deliberate to 0.01ms so every component respects OS motion preferences automatically (WCAG 2.3.3).

Tokens

RoleTokenValue
Immediate state snaps--duration-instant
Hover, colour and border transitions--duration-fast
Switch thumb, tooltips, toast exit, accordion--duration-base
Drawers, progress bar width--duration-slow
Long transitions--duration-deliberate
Default ease-out deceleration for UI state changes--ease-standard
Incoming menus, dialogs and drawers--ease-enter
Dismissing toasts and closing overlays--ease-exit
Playful overshoot for subtle emphasis--ease-spring
