How to use

  1. Link tokens/tokens.css and assets/components.css in your application shell.
  2. Toggle themes with data-theme="light" or data-theme="dark" on <html> (or press t on any page here).
  3. Consume tokens/tokens.json (278 W3C DTCG tokens) for Angular/Tailwind or build-time token generation.
<link rel="stylesheet" href="tokens/tokens.css">
