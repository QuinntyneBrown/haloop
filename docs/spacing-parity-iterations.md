# Haloop — Spacing-Only Visual Parity Iteration Log (20 Playwright CLI Iterations)

This document records **20 spacing-only Playwright CLI iterations** (margins, padding, vertical/horizontal gaps, responsive wrapping, and mobile viewport overflow containment) comparing the live Angular application (`http://localhost:4200`) against [docs/mocks/](mocks/README.md) across **Desktop (`1280×800`)** and **Mobile (`390×844`)** viewports.

Every iteration was measured using `npx playwright test e2e/spacing-parity.spec.ts --reporter=list`.

## Summary Metrics

- **Baseline Playwright spacing parity diffs (12 pages × 2 viewports):** `15` (`0px` collapsed section gaps on 7 pages across Desktop & Mobile + `81px` horizontal overflow on Mobile `/train`)
- **Final Playwright spacing parity diffs (12 pages × 2 viewports):** **`0`** (**100% parity** on `main.padding`, `main.gap`, exact `48px` desktop / `40px` mobile section gaps, `topbarHeight`, and `0px` horizontal overflow)
- **Final Playwright dialog spacing parity diffs (5 dialogs × 2 viewports):** **`0`** (**100% parity** on `.dialog`, `.dialog__panel`, `.dialog__header`, `.dialog__body`, `.dialog__footer` padding, margins, gaps, and `0px` mobile overflow)
